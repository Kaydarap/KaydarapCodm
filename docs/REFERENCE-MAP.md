# تطابق امکانات با سایت مرجع (iaslekar.ir)

**روش بررسی:** سایت مرجع یک اپلیکیشن React است (عنوان: ROYAL UNION | CODM ESPORTS). مسیرها، برچسب‌ها، متن‌ها و آدرس‌های API آن از فایل‌های JavaScript عمومی‌اش (۱۸ فایل صفحه) استخراج شد.
وارد پنل مدیریت آن نشدم، هیچ فرمی ارسال نکردم و پاسخ سرورهایش را ندیده‌ام. بنابراین رفتار سمت سرور (ذخیره ثبت‌نام، منطق بررسی‌ها، نتایج) را فقط از روی کد سمت کاربر توصیف می‌کنم.
لوگو، نام، متن‌ها و دارایی‌های مرجع کپی نشده‌اند.

## ب) قابلیت‌های اضافه KAYDARAP (پیشنهاد من، در مرجع نبود)

- کارت مستقل **Champion Rules** با لینک خارجی (تب جدید، `noopener`)
- چک‌لیست با تیک هر مرحله، نوار پیشرفت واقعی، ذخیره جداگانه Android/iOS، پاک کردن پیشرفت با تأیید دومرحله‌ای
- دکمه «ادامه از مرحله N» و نمایش پیشرفت در خانه
- حالت راهنمای مرحله‌به‌مرحله (یک مرحله در هر لحظه)
- لینک مستقیم به هر مرحله (`#step-3`) و کپی آن
- کپی کامل متن قوانین فقط به زبان انتخاب‌شده
- اشتراک‌گذاری (Share API یا کپی لینک) و **QR Code واقعی** که در خود مرورگر ساخته می‌شود
- جست‌وجوی قوانین با یکسان‌سازی حروف فارسی/عربی و فیلتر Android/iOS
- کلمات قابل کپی داخل متن (`cod`، `Check host`)
- برچسب‌های برجسته: `iOS 18+`، `iOS Beta` (غیرمجاز)، `Developer Mode: OFF`، `DNS: OFF`، `MT Manager` (غیرمجاز)
- نمایش نسخه و تاریخ آخرین ویرایش قوانین
- پیشنهاد تقریبی صفحه مناسب دستگاه (بدون هدایت اجباری)
- تنظیم شدت افکت‌ها (کامل/متعادل/کم)، حالت مطالعه، چهار اندازه متن، پشتیبانی از `prefers-reduced-motion`
- تغییر زبان روی همان صفحه و همان مرحله
- زمان روم‌ها به منطقه زمانی کاربر + شمارش معکوس
- بررسی خودکار کامل بودن ترجمه‌ها و علامت «Translation needs update» در پنل
- صفحه ۴۰۴ سه‌زبانه، sitemap با hreflang، تصویر پیش‌نمایش اشتراک‌گذاری
